Module 6: Add Score System

What You Will Learn

  • What a variable is
  • How to create a Score
  • How to add points when you catch an object

Step-by-Step Instructions

  1. Go to the Variables category (dark orange).
  2. Click Make a Variable and name it Score.
  3. Go to your Backdrop's code (or Player code) and add: when green flag clicked -> set [Score] to 0.
  4. Go back to your falling object's code. Find the if touching [Player] block.
  5. Inside that if, add change [Score] by 1.
