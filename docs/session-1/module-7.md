# Module 7: Win Condition

### What You Will Learn
- How to set a score target
- How to show a "You Win" message

### Step-by-Step Instructions
1. Go to your Backdrop's code.
2. Add a new `when green flag clicked` block.
3. Add a `forever` loop.
4. Inside, add an `if <> then` block.
5. For the condition, use the green Operator `[ ] > [ ]`. Put `Score` in the left box and `10` in the right box.
6. If Score > 10, add a block to `say [You Win!] for 2 seconds` (Looks - purple), and then `stop all` (Control).
