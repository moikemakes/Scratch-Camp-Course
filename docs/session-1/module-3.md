# Module 3: Add Background and Theme

### What You Will Learn
- How to change the Backdrop
- How to choose a player Sprite that fits your game world

### Step-by-Step Instructions
1. Look at the bottom right corner of the screen and click the **Choose a Backdrop** button (it looks like a little picture).
2. Pick a background for your game. (Is it a forest? Space? The ocean?)
3. Click the **Choose a Sprite** button (it looks like a cat face) to add a new player Sprite.
4. Delete any Sprites you don't need anymore.
