# Module 9: Increase Challenge

### What You Will Learn
- How to make the game harder and more fun
- How to change falling speeds

### Step-by-Step Instructions
1. Make your enemy fall faster! Change its falling speed to `change y by -8`.
2. Add more good objects by right-clicking your good object Sprite and selecting **duplicate**.
3. Make sure the duplicated objects fall from different starting spots at the top!
