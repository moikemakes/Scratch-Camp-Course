# Module 12: Playtesting

### What You Will Learn
- How to test your game like a real game developer
- How to fix bugs

### Step-by-Step Instructions
1. Swap seats with a partner.
2. Let them play your game without you telling them how.
3. Watch them play. Is it too hard? Too easy? Is anything broken?
4. Write down one thing you can fix or improve.
5. Go back to your computer and make that improvement!
