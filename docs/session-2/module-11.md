# Module 11: Improve Design

### What You Will Learn
- How to make your game look polished
- How to add a title screen

### Step-by-Step Instructions
1. Paint a new Sprite and use the Text tool to type your game's name. (This is your Title Screen!)
2. Add code to your Title Sprite: `when green flag clicked`, `show`, `go to x:0 y:0`.
3. Add a block to hide it after a few seconds: `wait 3 seconds`, then `hide`.
