# 🎮 Create Your Own Catching Game!

Welcome to the Scratch Catching Game course! In this guide, you will learn how to build your very own game where you control a character and catch falling objects.

**What you will create:**
A fun game where you move left and right to catch good items for points, avoid the bad items, and win the game!

---

# Before You Start

## What is Scratch?
Scratch is a fun way to learn coding! Instead of typing hard words, you snap colorful blocks together like LEGO. It is the perfect place to create your own games, stories, and animations.

## What you need:
- A computer with internet access
- Your Scratch account (go to [scratch.mit.edu](https://scratch.mit.edu) to log in)
- A big imagination! 🧠✨

## How to use this guide:
Read each module step-by-step. Don't rush! Make sure to test your game often. If you see a challenge, try it out!
